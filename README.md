# LaTeX Poster Template — A0 Landscape

A reusable LaTeX template for A0 landscape-orientation academic conference posters, by Polina Lemenkova.

The template is demonstrated with a worked example poster: **"Clustering Algorithm in ILWIS GIS for Classification of Landsat TM Scenes: Case Study of Mecsek Hills Region, Hungary"** (2012).

**DOI (ResearchGate):** https://doi.org/10.13140/RG.2.2.23963.31522
**Related (figshare):** https://doi.org/10.6084/m9.figshare.7440749.v1

## Usage
Copy this template as a starting point for a new poster, edit the title, author, sections and figures, and compile the main `.tex` file with a LaTeX toolchain (`pdflatex` / `xelatex` / `lualatex`) to produce the poster as a PDF at A0 landscape size.
